Where it fits, and where it does not

Fits: work where a program can tell a right step from a wrong one. Calculations, reconciliations, conversions.

Does not fit: judgement, writing, anything with no exact check. With no check there is nothing verified to teach from.

Rolling it out

1 · Pick one kind of work with an exact check. Write the check first. 2 · Set a held-out block aside and never touch it. 3 · Run the checked process wide; keep only what verified. 4 · Train, test cold, let the rule decide. 5 · Name the person who grants a change. 6 · Stop when a round fails its bar.

What this does — and doesn't — claim

One measured round is one measured round. not measured yet This model, this kind of problem. Nothing about others.

A cold answer is not a checked answer. not measured yet

The held-out problems are the same kinds of problem. New calculations from the same generator. The lift shows the skill carries to those, not elsewhere.

These are not The Climb's or The Crystal's numbers. Those run a 4-bit build in a browser tab with 128 tokens for one try. Here it is 32-bit on a laptop processor with 256, the same for both models.

The weights failed the plain hash check. The file's hash is not the maker's listed one. Every tensor was compared with a separate 8-bit copy instead, and all agree. How.

The trained weights are not published. Each adapter is recorded by its hash. Publishing weights derived from the model is a licence decision not yet taken.

A re-run may differ by a reply or two. Another processor can round a near-tie the other way. not measured yet

One test per round. An exact McNemar test at 0.05. Over several rounds the chance that one passes by luck adds up.
